A useful review checklist for a real buyer

Use it even if you hire elsewhere. Check that the vendor can return dated, reproducible evidence about your actual public endpoint.

  1. Record the exact authorized endpoint, deployment identity and observation timestamp.
  2. Verify that the published Agent Card, MCP manifests and documented protocol versions match actual public responses.
  3. For MCP, record `initialize`, `tools/list` and explicitly approved read-only tools; separate observations from inferred capabilities.
  4. For A2A, verify the actual advertised v1.0 and/or v0.3.0 message shapes and read-only responses, where authorized.
  5. Identify gaps in schema, error codes, onboarding and privacy without accessing secrets or creating marketplace records.
  6. Deliver a pass/gap/unknown table with source links, precise remediation and clear untested boundaries.
